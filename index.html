Sensor events: FRONT_TAPE FRONT_CLEAR REAR_TAPE FL_ON/OFF FRI_ON/OFF FRO_ON/OFF BL_ON/OFF BR_ON/OFF FOLLOW_LOST (both FR white for “lost time” while following) TRACKWIRE TRACKWIRE_LOST BEACON BEACON_LOST BUMP_FRONT BUMP_BACK BUMP
if sensors: fl fri fro bl br front rear tape trackwire beacon bumpf bumpb
Robot: 10×10 in, wheels mid-left/right, everything fires/senses out the right. Tape boards FL, FR inner, FR outer, BL, BR. Bumper bars front + back only (sides blind).
Robot menu: Text FSM runs the program above on the sim's default robot. design.md HSM runs the team design's HSM (§8–§9) on the design.md robot: 7 tape sensors FL FC FR / MC / BL BC BR (1.5" apart; FC 0.5" ahead of FL/FR, BC 0.5" behind BL/BR), front + back bumpers, side shooter + track-wire coil + tower-tape sensor on the right (the sensor looks sideways, mounted directly below the shooter, and sees the tower's vertical banner under the marked hole), beacon detector on the left. It drives counterclockwise so the shooter faces the towers and the beacon faces the field. Tower: no track wire — while following, the tower-tape sensor sees the banner below the marked hole → stop → fire. Dead robot: beacon seen → center it abeam → rotate 180° → fire, drive 0.5 s, fire, drive 0.5 s, fire (3 shots) → rotate back. Only 6 balls: 3 stay reserved for the dead robot until the attack is done. with fixes adds the fixes found in testing.
Rules: DQ if the robot's center passes the tape's outer edge, or it stays in contact > 5 s. Win = 2 marked-hole towers + 2 opponent hits in 2:00.
